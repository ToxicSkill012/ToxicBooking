# ToxicBooking — бронирование ПК в Toxic Skill

Telegram Mini App: клиент выбирает зону, пакет или **своё время** (от 30 минут), точное время до минуты
и свободный ПК — один или сразу несколько для команды. Данные о живых сессиях приходят из Gizmo через мост.

## Как устроена бронь (v4)

1. **Формат** — зона (вкладки), число игроков (1–8) и **пакет** или **своё время**.
   Своё время — по часовому тарифу зоны за каждые начатые 30 минут; если пакет выходит дешевле, приложение подскажет,
   а сервер в любом случае возьмёт меньшую цену.
2. **Когда** — день и время на ленте (листается пальцем с инерцией, тап — прыжок, ± — по минуте).
   На ленте видно, где мало свободных ПК или все заняты; кнопка «С 19:20» ставит ближайшее подходящее время.
3. **ПК** — показываются только компьютеры, свободные на выбранный отрезок. Для команды — «Подобрать рядом».
4. **Итог** — имя, телефон, сумма. Бронь для команды создаётся **одной операцией**: все ПК или ни одного.

Цену **считает сервер** (`TARIFF` в `backend/Code.gs`), а не приложение. Цены и ПК заданы в двух местах —
`js/core/config.js` (`ZONES`: `hour`, `pkgs`, `layout`) и `backend/Code.gs` (`TARIFF`, `RULES`): меняешь — меняй в обоих.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Разметка всех экранов (Vercel отдаёт его как сайт) |
| `css/app.css` | Основные стили |
| `css/glass.css` | Стиль «стекло» как в iOS + облегчённый режим для слабых телефонов |
| `js/core/` | Общее: язык, настройки зон и цен (`config.js`), время клуба (`clock.js`), API, навигация, живой статус ПК (`live.js`) |
| `js/screens/` | Экраны: главная, мои брони, профиль, награды, настройки, промокоды |
| `js/booking/` | Бронь: шаги (`booking.js`), лента времени и ползунок длительности (`time-picker.js`) |
| `js/admin/` | Панель владельца и оффлайн-брони |
| `js/extras/` | Подсказки, «Что нового», змейка, эффекты |
| `backend/Code.gs` | Код Google Apps Script (бэкенд на Google Таблице) |
| `bridge/` | Мост Gizmo → приложение (PowerShell, для ПК с сервером Gizmo) |

Скрипты подключаются обычными `<script defer>` в `index.html`, порядок важен. Сборка не нужна.
После правок увеличь `?v=4.0.1` в `index.html`, чтобы телефоны не брали старые файлы из кэша.

## Как обновить (по порядку)

### 1. Сайт (Vercel)
Влей ветку в `main` — Vercel опубликует сам. Новый сайт работает и со старым бэкендом
(бронь для команды тогда создаётся по одному ПК), но цены и проверки v7 заработают только после шага 2.

### 2. Бэкенд (Apps Script)
1. Открой проект Apps Script → замени весь код на `backend/Code.gs`.
2. **Секреты больше не хранятся в коде.** Без них админка пишет «нет доступа», а уведомления в Telegram не уходят
   (в панели владельца теперь видно, каких именно не хватает). Шестерёнка «Настройки проекта» → «Свойства скрипта» → добавь:
   - `BOT_TOKEN` — токен бота-уведомлений (@toxicskill_booking_bot)
   - `USER_BOT_TOKEN` — токен клиентского бота (@toxicskill_bot)
   - `ADMIN_KEY` — длинный секрет для входа владельца по 🔑
   - `BRIDGE_KEY` — секрет для моста Gizmo (любой длинный набор букв и цифр)
   - `ADMIN_CHAT_ID` — если уведомления должны идти в другой чат (необязательно)

   Можно и через функцию `setupSecrets()`: вписать значения, запустить один раз, потом стереть их из кода.
   Свойства начинают работать сразу, переразвёртывать ради них не нужно.
3. Запусти один раз `setupAllSheets` (добавит колонку `group` для брони команды) и `setupTriggers` (выбрать функцию → «Выполнить»).
4. «Начать развёртывание» → «Управление развёртываниями» → ✏️ → Версия: **Новая версия** → «Развернуть».
   Адрес `/exec` не меняется, сайт править не нужно.

### 3. Мост Gizmo
Нужен, чтобы в приложении было видно «занят до 19:45 · ещё 1 ч 12 мин».

1. В Gizmo включи API: настройки → **Web portal** (вместе с ним включается Web API). Запомни порт (обычно 80).
2. Скопируй папку `bridge` на ПК с сервером Gizmo, например в `C:\ToxicBridge`.
3. Скопируй `bridge.config.example.json` → `bridge.config.json` и заполни:
   - `gizmoUrl` — `http://127.0.0.1:80` (свой порт), `gizmoUser` / `gizmoPassword` — логин оператора Gizmo;
   - `appUrl` — адрес Apps Script `.../exec`, `bridgeKey` — тот же `BRIDGE_KEY`;
   - `hostMap` — как ПК называются в Gizmo → как в приложении (`"PC-01": "ST-01"`, по номеру: `"#21": "BC-01"`,
     `""` — не показывать). Имена вида `ST-01`, `VIP 2`, `BC05` распознаются сами.
4. Запусти `probe.cmd` — он проверит API и сохранит отчёт `probe.txt`: какие адреса работают и что уйдёт в приложение.
   Сверь «осталось N мин» с Gizmo; если отличается в 60 раз — поставь `"timeUnit": "seconds"` или `"minutes"`.
5. `start-bridge.cmd` — запустить в окне. Чтобы работал всегда: `install-autostart.cmd` → «Запуск от имени администратора».
   Лог — `bridge.log` рядом со скриптом. Убрать из автозапуска — `uninstall-autostart.cmd`.

Если остаток времени неизвестен (постоплата, нет баланса), ПК считается занятым до конца брони на нём,
а без брони — ещё 60 минут (`GIZMO_UNKNOWN_BUSY_MIN` в `Code.gs`). Если мост молчит дольше 5 минут,
данные Gizmo не используются — остаются только брони.

**Занятость не видна?** В панели владельца (Настройки → админ) есть карточка «Мост Gizmo»: когда мост последний раз
присылал данные и не стучится ли он без ключа. Там же — готовый адрес с ключом и кнопка «Копировать».

**Старый мост из консоли** (тот, что запускался командой и шлёт `action=gizmoSync&hosts=ST-01:1,ST-02:0`)
работает как раньше, **без ключа** — достаточно запустить его и не закрывать окно консоли.
Если мост знает, сколько осталось, добавь минуты: `ST-01:1:45` — тогда клиенты увидят «занят до 19:45».
По желанию закрой доступ посторонним: добавь мосту `&key=BRIDGE_KEY` и свойство скрипта `BRIDGE_STRICT` = `1`
(тогда сервер пускает мост только с ключом). Без ключа мост не получает телефоны клиентов в `getPendingBookings`.
POST тоже работает: `{"action":"gizmoSync","key":"...","hosts":[{"pc":"ST-01","busy":true,"left":45}]}`.

## Безопасность (что изменилось в бэкенде v6)
- Токены ботов и ключ админа — в «Свойствах скрипта», не в коде.
- Telegram ID клиента берётся только из подписанных `initData` (подпись проверяется токеном бота),
  чужие баллы, брони и награды получить нельзя.
- Общий список броней — без имён и телефонов; свои брони — по подписи; полный список — только владельцу.
- Gizmo-мост, промокоды и админ-функции — только с ключом.
